# Fraud Detection ML Service (v2)

Проект потокового обнаружения мошеннических транзакций с использованием Kafka, PostgreSQL, Streamlit UI, ML-модели CatBoost, а также мониторинга (Grafana). Проект реализован в рамках ДЗ по MLOps, ШАД МТС.

---

## Архитектура

| Сервис | Описание                                                                           |
|--------|------------------------------------------------------------------------------------|
| **Kafka** | Шина сообщений                                                                     |
| **Zookeeper** | Координация Kafka                                                                  |
| **Kafka UI** | Веб-интерфейс для мониторинга Kafka                                                |
| **fraud_detector** | Микросервис на Python, выполняющий предобработку данных и инференс модели CatBoost |
| **scoring_writer** | Потребитель Kafka, сохраняет результаты скоринга в PostgreSQL                      |
| **PostgreSQL** | Хранилище результатов                                                              |
| **interface** | Веб-интерфейс (Streamlit) для загрузки файлов и просмотра результатов              |
| **Grafana** | Визуализация метрик и дашборды                                                     |

## Функциональность

### 1. Обработка потока транзакций из Kafka
- Streamlit UI загружает CSV-файл, генерирует уникальный `transaction_id` и отправляет каждую транзакцию в топик `transactions`.
- `fraud_detector` читает сообщения, выполняет препроцессинг (таргет-энкодинг, временные признаки, расстояние, лог-трансформация) и инференс модели CatBoost (только CPU).
- Результат (`score`, `fraud_flag`, `us_state`, `merchant`, `cat_id`) отправляется в топик `scoring`.

### 2. Хранение результатов в PostgreSQL
- `scoring_writer` читает топик `scoring` и вставляет записи в таблицу `scores` (поля: `transaction_id`, `score`, `fraud_flag`, `us_state`, `merchant`, `cat_id`, `created_at`).

### 3. UI Streamlit
- Загрузка CSV и отправка в Kafka.
- Кнопка **Посмотреть результаты**:
  - Вывод **10 последних фродовых транзакций** (`fraud_flag == 1`).
  - Гистограмма распределения скоров по **последним 100 транзакциям**.

### 4. Мониторинг и дашборды Grafana
- Дашборд **Fraud Detection Advanced** включает:
  - **TPS (транзакций в секунду)** с фильтрацией по штатам (us_state) и мерчендайзерам (merch).  
  - **Плотность распределения скоров** (гистограмма) с фильтрацией по штатам и мерчендайзерам.  
  - **Barplot средней доли фродовых транзакций по категории продукта (cat_id)** для последних 1000 транзакций, также с учётом фильтров.  
- Выпадающие списки для выбора штата и мерчендайзера (мультивыбор, опция «All»).  
- Графики динамически обновляются при изменении фильтров или временного диапазона.

## Запуск проекта

### Требования
- Docker (20.10+) и Docker Compose (2.0+)
- 4 ГБ свободного места

### Шаги

1. Создайте `.env` файл и заполните по шаблону `.example-env`

2. Запустите контейнеры

```bash
docker-compose up --build
```

Первый запуск может занять несколько минут.

## Таблица в PostgreSQL

Таблица `scores` содержит следующие поля:

| Поле             | Тип          | Описание                                |
|------------------|--------------|-----------------------------------------|
| id               | SERIAL       | Уникальный ID                           |
| transaction_id   | TEXT         | Идентификатор транзакции                |
| score            | FLOAT        | Вероятность мошенничества (порог = 0,5) |
| fraud_flag       | INT          | 1 - мошенничество, 0 - норма            |
| created_at       | TIMESTAMP    | Дата и время записи                     |

## Как использовать

1. Перейдите в браузере по адресу: [http://localhost:8501](http://localhost:8501)
2. Загрузите CSV файл с данными транзакций.
3. Нажмите "Отправить", чтобы данные попали в Kafka.
4. После обработки можно нажать "Посмотреть результаты":
   - Отобразятся последние 10 фродовых транзакций
   - Будет показана гистограмма скоров последних 100 транзакций
5. Для просмотра метрик откройте Grafana [http://localhost:3000](http://localhost:3000)
