# Fraud Detection ML Service

Сервис для автоматического обнаружения мошеннических транзакций в режиме батчевого скоринга в рамках ДЗ по MLOps, ШАД МТС

## Архитектура решения

```
├── .gitignore
├── Dockerfile
├── README.md
├── requirements.txt
├── app/
│ └── app.py # Ядро сервиса с обработчиком файлов
├── src/
│   ├── preprocessing.py    # Пайплайн обработки данных
│   ├── scorer.py           # Модуль прогнозирования
│   └── utils.py            # Получение топ 5 feature importances и графика плотности предсказанных вероятностей
├── models/                 
│   ├── catboost_model.cbm  # Сериализованная модель CatBoost
│   ├── target_encoder.pkl  # Обученный таргет-энкодер от CatBoost
│   └── imputer.pkl         # Обученный импьютер для непрерывных признаков
├── input/                  # Директория для загрузки файлов на скоринг
└── output/                 # Директория с результатами скоринга
```

## Ключевые особенности

### Пайплайн препроцессинга (`preprocessing.py`)
1. **Таргет-энкодинг** категориальных признаков (`merch`, `cat_id`, `full_name`, `gender`, `street`, `one_city`, `us_state`, `post_code`, `jobs`) с использованием `CatBoostEncoder` (leave-one-out)
2. **Временные признаки** – час, год, месяц, день месяца, день недели, сезон
3. **Географические признаки** – координаты клиента и мерчанта и расстояние между ними (формула гаверсинуса, км)
4. **Импьютация** непрерывных признаков (`amount`, `population_city`, `distance`) средними значениями (обученными на трейне)
5. **Логарифмическое преобразование** – `amount_log`, `population_city_log`, `distance_log` для стабилизации дисперсии

### Модельный слой (`scorer.py`)
- Используется **CatBoostClassifier**, обученный на предобработанных данных
- **Порог классификации:** 0.5
- **Результат** - DataFrame с колонками `id` и `prediction`

### Анализ работы модели
- `utils/get_feature_importance` – получить топ-5 наиболее важных признаков модели с их feature importance
- `utils/get_prediction_density_plot` – получить график плотности распределения предсказанных вероятностей для обработанного датасета

### Наблюдение за файлами
- Используется `PollingObserver` из `watchdog` – периодическое сканирование папки `./input`
- При появлении файла с расширением `.csv` автоматически запускается полный пайплайн

### Логирование
- Запись логов всех событий в файл `/app/logs/service.log`
- Консольный вывод для мониторинга в реальном времени
- Виды логов: 
  - `INFO` - основные этапы обработки 
  - `DEBUG` - детали преобразования данных
  - `ERROR` - критические сбои

## Быстрый старт

### Требования
- Docker 20.10+
- 2 ГБ свободного места
- Порты: только файловая система

### Запуск сервиса

1. Скачайте файл `test.csv` из соревнования https://www.kaggle.com/competitions/teta-ml-1-2025

2. Соберите Docker-образ:
   ```bash
   docker build -t fraud_detector .
   ```

3. Запустите контейнер с монтированием папок:
   ```bash
   docker run -it --rm -v ./input:/app/input -v ./output:/app/output fraud_detector
   ```

   После успешного запуска в логах появится сообщение:
   ```
   __main__ - INFO - File observer started on /app/input
   ```

4. Поместите файл `test.csv` в папку `./input`

5. Результаты появятся в папке `./output`:
   - `predictions_<timestamp>_<file_name>.csv` – предсказания в требуемом формате
   - `feature_importance_top5_<timestamp>.json` – топ-5 важных фичей
   - `prediction_density_<timestamp>_<file_name>.png` – график плотности предсказаний
